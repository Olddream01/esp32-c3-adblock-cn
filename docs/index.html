🛡️ C3 AdBlock 定制版

ESP32-C3 全网 DNS 广告拦截器 —— 上游换成国内 DNSPod，WiFi 配置改成真正持久。

把 ESP32-C3 SuperMini 用数据线插到这个电脑，然后：

你的浏览器不支持串口 —— 请改用桌面版 Chrome 或 Edge。 你需要先允许浏览器访问串口。
Chrome / Edge 桌面版 约 30 秒 上游 119.29.29.29 WiFi 不再丢
✅ 这版相对官方预编译固件改了什么
上游 DNSQuad9 9.9.9.9 → DNSPod 119.29.29.29（国内可达，不易被劫持）
WiFi 持久化凭据双备份：NVS + LittleFS /wifi.cfg；NVS 丢了会自动从备份恢复并回写
重启后重连开机连网改 3 次 × 20 秒重试；连不上时后台每 15 秒继续重试，路由器一恢复就自己接上
误触 BOOT清空 WiFi 的触发条件从「按住 60 毫秒」改成按住 3 秒，插线时蹭到按钮不再清空
配网页自动填好上次保存的 WiFi 名字，一眼能看出配置还在不在
断线自愈运行中掉线自动重连，不会悄悄变成一个没人能访问的 DNS
安全官方预编译固件是 7 月 26 日的版本，完全没有密码保护；这版带 Basic Auth + CSRF 校验，而且不内置任何可用密码——密码在配网页或面板里现场设定，存在设备 NVS
封禁列表直接内置官方本周列表 129,651 条（官方预编译版只有约 5.7 万条）
刷完之后
  1. 如果之前已经配过 WiFi，新固件会自动连上（NVS 里存的配置被直接继承了），不用重新配。
  2. 没有配置过的话，手机连上热点 C3-AdBlock-XXXX，弹出的页面里填 WiFi 密码即可。
  3. 面板：http://c3adblock.local（Windows 解析不了就用路由器后台里的那个 IP）。

这版不擦除整片 flash（manifest 里关掉了 erase 提示），所以 NVS 里的 WiFi 配置能活下来。首次如果浏览器问要不要擦除，选不擦。

🔐 刷完第一件事：设自己的面板密码

固件里没有内置任何可用密码（编译期用的是上游占位符），这样公开分发才不会变成"谁都能改你的设备"。

  1. 配网页（首次开机时手机连 C3-AdBlock-XXXX 弹出的那个）里有两个可选输入框：Dashboard password 和 Network OTA password，都填上自己的（≥6 位）。
  2. 如果刷的时候 NVS 里已经有 WiFi 配置、配网页没出现，就直接打开面板，用默认口令 admin / CHANGE_ME_WEB_PASSWORD 登录，然后在 SECURITY — PASSWORDS 一栏改掉。

密码存在设备本地的 NVS 里，重启、重刷封禁列表都不会丢，也不需要重新烧录。
